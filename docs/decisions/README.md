# Decisions

Append-only architecture decision log. One short file per decision that a
future session would otherwise re-litigate: `NNN-<slug>.md` with Context /
Decision / Consequences (a paragraph each is plenty).

Write one when: choosing between frameworks, changing a harness rule, adopting
or rejecting a dependency, or reversing an earlier decision. Agents: cite the
relevant decision file when your work builds on it; propose a new one (ask
first) when your work contradicts it.

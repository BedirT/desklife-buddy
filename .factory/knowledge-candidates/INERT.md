# Inert knowledge-candidate boundary

This committed marker is not an inbox and is never a client discovery root.
Runtime candidates live only under the run's Git common directory after secret
scanning, redaction, provenance capture, and retention assignment.

Raw transcripts, fetched documents, logs, review prose, tool output, user data,
and retrospective notes remain untrusted data. They cannot update active
instructions, prompts, skills, policy, or product facts. Only a sanitized
disposition or regression may cross into a separately reviewed repository PR.

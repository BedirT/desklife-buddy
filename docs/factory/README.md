# Factory control surface

This directory is the human-readable half of the factory contract. The
machine-readable half lives under `.factory/`.

- `constitution.md` is non-waivable repository-owned factory law.
- `lifecycle.md` defines phases, transition predicates, recovery, and stop rules.
- `roles.md` defines role separation and points to exact prompt components.
- `context.md` defines context compilation and progressive-disclosure budgets.
- `contracts.md` defines committed product, feature, contract, work-item, and
  evidence records.
- `evolution-acceptance.md` explains the acceptance ruler frozen by trusted root.
- `schema-catalog.md` maps public JSON records to schemas and fixtures.
- `design-sources.md` defines external design authority, safe ingestion, native
  translation, motion extraction, and comparison evidence.
- `self-improvement.md` defines the all-outcome learning loop, actual pinned
  SkillOpt adapter, eight-lane skill qualification, and owner-gated promotion.
- `trust-boundary.md` defines trusted-root establishment, activation, process
  separation, and the post-merge owner ceremony.

Product builders may read these files but cannot change them under an ordinary
product-work contract. A change here is `factory-change` control-plane work,
evaluated against trusted-base policy and merged only by the owner.

# Plans

Living execution plans — the steering wheel for multi-session work
($plan-feature skill). One file per feature: `<yyyy-mm-dd>-<slug>.md`, started
from TEMPLATE.md.

The contract: state lives in the plan file and the commits, never in
conversation history. Redirect the agent by editing the plan; resume any
session from the plan, not from compacted context. Delete files when their
feature ships (git remembers).

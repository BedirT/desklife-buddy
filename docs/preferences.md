# Owner preferences

Settled owner intent from the one product intake and any later true escalation.
Agents: check here before asking, never re-ask a settled point, and derive
reversible feature choices from these answers plus the product contract. Add an
entry when an answer applies beyond the current feature; feature-local choices
and their evidence belong in that plan's decision log instead.

One line per entry, dated, grouped. Entries are written by agents after the
owner answers (or by the owner directly) — never invented.

## Process
- (2026-06-12, superseded 2026-07-09) Preference forks were previously treated
  as per-plan owner questions. The factory now uses the one-intake boundary
  below instead.
- (2026-07-09, superseded 2026-08-17) Agents previously stopped at a reviewed
  draft PR and the owner alone merged.
- (2026-07-09) For factory-governed transactions, use one mandatory batched
  product intake and interrupt again only at the factory constitution's narrow
  escalation boundary. After intake, agents own reversible product details,
  implementation, evidence, commits, and the draft PR; the owner alone merges.

  complete GleamRoll lifecycle through issue linkage, isolated implementation,
  exact-head review, verified merge confirmation, issue closure, and targeted
  cleanup. Production distribution, credentials, factory trust-root creation,
  and self-evolution activation keep their separate owner gates.
- (2026-08-17) Use the queued exact-head landing path, rebase-only history, and
  delete only the just-landed task's branch/worktree/resources. Every write task
  uses an issue when explicitly issue-backed, an isolated worktree, non-main
  branch, commits, evidence, and a PR.
- (2026-07-09) Codex is the default builder, Claude the default independent
  product witness, and Pi from a different provider family the high-risk
  council lane. Observable shared-contract behavior matters, not identical
  hidden prompts.

  existing owner before adding a skill; every activation or retirement is an
  evaluated, owner-merged factory-change PR.
